# GrievanceGrid

A mobile and web prototype for four visible civic complaint categories. Citizens keep individual tracking records; authorised municipal officers control review and outcomes.

## First milestone

This repository is being built around one working path: **submit a complaint → receive a tracking ID → authorised officer review → citizen sees the update**.

React Native/Expo + TypeScript (mobile), Next.js + TypeScript (web), FastAPI + Python (API), PostgreSQL + PostGIS (database).

This is an academic prototype, not an official grievance portal or emergency service. AI models are not trained or enabled in this milestone. No real citizen records, private photos, credentials or downloaded datasets belong in Git.
